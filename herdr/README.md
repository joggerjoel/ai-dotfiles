# Herdr application integration

Reserve this directory for Herdr application-specific configuration and integration
notes. No standalone application files were identified here during the separation.

Reusable orchestration is maintained in the sibling
[herdr-orchestrator project](../../herdr-orchestrator/README.md).
The third-party Agent Orchestrator checkout is maintained separately in
[agent-orchestrator](../../agent-orchestrator/README.md).
Neutral benchmarks and reporting belong in
[workflow-test](../../workflow-test/README.md).

Do not place those projects, reference checkouts, or benchmark evidence in this
directory. Their own Herdr adapters remain with their owning orchestration project.
