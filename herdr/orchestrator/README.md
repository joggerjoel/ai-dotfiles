# Building Herdr master control

Start with the [build guide](guides/building-herdr.md). It identifies the current design,
implementation order, verification commands, and review evidence.

## Current authority

- [Master plan](master-control-herdr-plan.md): baseline design.
- [Merge plan](merge-busybrain-herdr-plan.md): explicit amendments, including intake, recovery,
  quota, real-app verification, and supervisor-enforced design quality.
- [Master TODO](master-control-herdr-todo.md) and [merge TODO](merge-busybrain-herdr-todo.md):
  implementation work. Unchecked work is not implemented merely because its design is approved.
- [Council resolution](merge-busybrain-herdr-council-resolution.md): disposition of the 22
  capability-grid review entries, not a claim that every historical finding is closed.

## Evidence inventory

See [review inventory](inventory/reviews/README.md) for the capability grid, full council report,
detailed findings, broader Markdown audit, and retained machine-readable evidence.

Historical reports preserve earlier claims and quotations. Follow the current plan for adopted
rules; revalidate unresolved historical findings before changing code. Runtime status belongs in
supervisor state, not in this document collection.
