1. **Run 1's "Built (unmerged): none identified" was an unrun check, and it hid a real
   bug.** `origin/fix/homebrew-shellenv-module` carries a finished fix for a silent,
   total PATH failure on Apple Silicon: without `zsh/modules/homebrew.zsh`, a missing
   `~/.zprofile` line strips `/opt/homebrew/bin` entirely, and the `command -v` guards in
   `modules.conf` then answer false for the wrong reason. All three of the branch's
   pieces confirmed absent from main. Stranded 7 days.
2. **Two independent references converge on the same P1.** qm and firstmate both ship a
   harness-independent command policy. Ours binds Claude only — 9 rules in
   `profiles/*/settings.json`, nothing for codex/opencode/gemini/pi/grok. Convergence
   from two unrelated projects is a stronger signal than either alone.
3. **The P1 implementation is already on disk.** `scripts/provision-firstmate.sh:122`
   clones firstmate to `~/firstmate`, then stops at binary verification; line 137 hands
   the rest to the operator. So macstudio has firstmate's
   one-classifier-plus-per-harness-transport policy sitting unconfigured in a clone this
   repo pays to install.
4. **The fork parent is exhausted.** `iamnolanhu/claude-dotfiles` is 46 blobs, 20 commits,
   1 star, last commit 2026-08-11. Content diffs run the other way — upstream lacks our
   verification layer, our `INJECTION_GUARD_MODE`, our permission migration. Drop it.
5. **`archive/symlink-repair-original` is correctly named**, not stranded: `lib/links.sh`,
   `relink_all` and `tests/preflight/run.sh` all reached main by another route.
